# R6 Guia Tático

Site desenvolvido para apresentar informações e estratégias de **Rainbow Six Siege**, com foco em operadores e mapas.

O projeto foi desenvolvido como prática de **desenvolvimento Front-End**, utilizando HTML e CSS.

## Sobre o projeto

O site funciona como um guia tático, reunindo informações de operadores e mapas do jogo em uma interface simples e organizada.

A ideia foi aplicar conceitos de estruturação de páginas, navegação, organização de conteúdo e estilização.

## Funcionalidades

* Página inicial
* Guia de operadores
* Informações sobre mapas
* Navegação entre páginas
* Cards para apresentação dos operadores
* Layout responsivo
* Interface inspirada na identidade visual de Rainbow Six Siege

## Tecnologias

* HTML5
* CSS3
* Flexbox
* CSS Grid

## Estrutura

```text
r6-guia-tatico/
│

├── mapas.html
├── style.css
└── imagens/
```

## Como executar

Não é necessário instalar nenhuma dependência.

Clone o repositório:

```bash
git clone https://github.com/rogersambulski/r6-guia-tatico.git
```

Depois, abra o `index.html` no navegador.

O projeto foi desenvolvido para praticar conceitos de **Front-End** e transformar conhecimentos de HTML e CSS em uma aplicação web funcional.
